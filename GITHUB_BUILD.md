# Build APK with GitHub Actions

1. Upload the **contents of this folder** to the repository root.
2. Open the repository **Actions** tab.
3. Open **Build Android APK**.
4. If a run did not start automatically, choose **Run workflow**.
5. Wait for the build to complete with a green check mark.
6. Open the completed run and download the **Course-Schedule-Planner-APK** artifact.
7. Extract the downloaded artifact ZIP to get `app-debug.apk`.

The workflow builds a debug APK for direct device testing.
